# Zulnasri Portfolio V3

Personalized portfolio built with HTML, CSS, and JavaScript.

## Sections

1. Hero
2. About
3. Education History
4. Skills
5. Projects
6. Working Experience
7. Contact

## Run in Laragon

Put this folder in:

`C:\laragon\www\`

Example:

`C:\laragon\www\zulnasri-portfolio-v3\`

Start Laragon and open:

`http://localhost/zulnasri-portfolio-v3/`

## Add your profile photo

Put your photo here:

`assets/images/profile.jpg`

If the image is missing, a placeholder appears automatically.

## Add your resume

Put your resume here:

`assets/resume/Zulnasri_Resume.pdf`

## Add project screenshots

Put screenshots here:

`assets/projects/`

Current expected image names:

- `jit-inventory.jpg`
- `heart-disease-prediction.jpg`
- `automotive-price-prediction.jpg`

## Add future projects

Open:

`projects.js`

Copy one project object and paste it before the final `];`.

You do not need to change `index.html` when adding projects.

## GitHub Pages

This portfolio uses only HTML, CSS and JavaScript, so it is suitable for GitHub Pages.
